- 发布者：Mikuláš He

该 Kaggle 数据卡说明其中图片是从 Google Images 下载的，但没有为每张图片列出原作者、原始网址或单独授权。Kaggle 页面上的 `GPL 2` 标注不一定能够解决每张原始图片可能存在的版权、商标、隐私或其他权利问题。

本仓库按来源数据集中的文件形式提供少量图片，仅用于个人学术研究和非商业测试，不对其权利状态作额外保证。需要公开发布、制作衍生作品或用于其他场景时，使用者应自行核实对应图片的原始权利和授权；无法确认时应停止使用并从本地副本中删除。
